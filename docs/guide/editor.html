The editor tools

The Logic I/O panel is where you make connections. The viewport shows them back to you as wires, and the Scene tree warns you when something is set up wrong.

The Logic I/O panel

Select any Logic Node and the Logic I/O tab in the bottom panel shows its connections. The title line names the node and its type. The panel has two tabs.

Sends To

The connections this node sends. Click + Add Output to add a row, then fill it in from left to right:

ColumnWhat it does
My OutputThe event on this node that starts the connection.
TargetThe node that receives it. Pick from the list, or click … to pick from Godot's searchable scene tree, which also reaches nodes inside placed scenes.
Target InputWhat the target does when the signal arrives. The list only shows inputs the target actually has.
DelayExtra seconds to wait before calling the input. Adds to any delay the node has itself, such as a Relay's own Delay. See Delays.
OnceOnly send this connection the first time the output fires.
✕Delete the row.

Received From

A read-only list of every connection in the scene that points at the selected node, with its delay and Once flag. Double-click a row to jump to the node that sends it. This is how you answer "what opens this door?"

Tooltips

Hover any column header, any choice in a dropdown, or any Received From row for a one-line explanation, for example "Flip the value." on Branch's Toggle. The text comes from the same descriptions Godot shows in the Inspector and the built-in help, so the three always agree.

Show all nodes

By default the Target list only shows Logic Nodes. Tick Show all nodes to target any node, for example an AnimationPlayer. See Connecting to built-in Godot nodes.

Undo

Every change in the panel is an ordinary editor action: Ctrl+Z undoes it and Ctrl+Shift+Z redoes it.

In the viewport

Badges

Each Logic Node shows its family badge in the 3D view, drawn on top of walls and floors so it's never hidden.

Wires

Every connection is drawn as a thin line from the sending node to its target, in the sender's family color. Select a node, or a node it targets such as a door, and its wires switch to thicker, see-through tubes with gentle pulses traveling toward the receiving end. A busy level stays readable, and the selected logic stands out.

Trigger boxes

Trigger Volumes and Interact Zones draw their box as a see-through orange volume. Click an edge of the box to select it, the same as Godot's own shapes. Set Volume Color to tint a box so different triggers are easy to tell apart; it's only drawn in the editor.

Move paths

A Move node draws a cyan line from what it moves to where it ends up, so you can check the direction before you press play.

Hiding them

Each node type has its own toggle under View > Gizmos in the 3D viewport, for example "Logic Trigger" or "Logic Audio Clip". Turn a type off to hide its badges and wires while you work on something else.

Placing nodes

Logic Nodes are added like any other node, with Add Child Node (Ctrl+A). A new Logic Node lands in front of the editor camera, on the surface you're looking at, at a whole-number position, instead of at the world origin. Each node has its own icon in the Scene tree, in Godot's 3D red, so they read as part of Godot.

Warnings

When a node is set up in a way that can't work, Godot shows a ⚠ next to it in the Scene tree. Hover it to see why. Logic Nodes warn about:

  • Connections whose output, target or input no longer exists, for example after a target was deleted or renamed.
  • Empty rows.
  • A Move or Rotate with nothing to move, or an offset of zero.
  • A moving StaticBody3D, which the player won't ride along with. Use an AnimatableBody3D instead.
  • A Trigger Volume or Interact Zone with an empty Collision Mask, or an Interact Zone whose action isn't in the Input Map.
  • An Audio Clip with no sound chosen, and a Counter whose Start Count is already at its Goal.

Logic inside placed scenes (prefabs)

You can build logic into a scene, such as a button that clicks and lights up when pressed, and place that scene in many levels. When you select a Logic Node inside a placed scene:

  • The rows saved in the button's own scene show greyed out. Open that scene to change them; the title line tells you which file they come from.
  • Rows you add here are saved in the level, on top of the button's own rows. That's how each copy of the button can open a different door while still playing its own click.
  • Changes you later make to the button's own rows still reach every copy.
One level deep

This layering works for one level of nesting: a prefab placed in a level. A prefab inside another prefab inside a level isn't supported yet.
