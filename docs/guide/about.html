Limitations and credits

What this release does and doesn't do, what's planned, and who made what.

Known limitations

  • 3D only. Logic Nodes are Node3Ds. 2D scenes aren't supported.
  • Nothing is saved. A Counter's count, a Branch's value and every Once flag reset when the scene loads. There's no save/load of node state.
  • Single-player. There's no multiplayer sync, and an Interact Zone only credits the first body inside it when several are in it at once (#6).
  • Prefab layering is one level deep. Rows added to a placed scene work; a placed scene inside another placed scene isn't supported yet.
  • Picking a Target uses the dropdown or Godot's scene-tree picker (the … button). Clicking an object in the viewport to pick it isn't available yet.
  • Relay Delay vs. connection Delay. Both work as documented in Delays, but the panel doesn't yet show a Relay's own Delay next to its rows (#12).
  • GDScript build only. The .NET build of Godot hasn't been tested, and there's no C# API.

Open issues are tracked on GitHub.

Planned for later

  • Picking a Target by clicking it in the viewport.
  • Drawing connections directly in the viewport.
  • Custom events sent from game code.
  • Save/load of node state, 2D support and multiplayer.

A separate node-graph view is not planned. Building the logic inside the level, next to what it controls, is the point of the project.
