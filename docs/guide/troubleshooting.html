Troubleshooting

The problems people run into most, and the two tools for seeing what your logic is actually doing.

Seeing what your logic does

Trace

Tick Trace on any Logic Node and, while the game runs, the Output panel prints every input it receives and every output it fires, with the activator:

[Trigger] → on_trigger_enter (activator: Player) [Door Move] ← go_to_end (activator: Player) [Door Move] → on_move_start (activator: Player)

→ is an output firing, ← is an input arriving. Turn Trace on for every node in a chain to follow a signal from start to finish. If a line you expect never appears, the break is just before it.

The Debug node

Wire a Debug node into the middle of a chain to see a message on the game screen when the signal passes through. It passes the event on, so the chain keeps working, and it shows nothing in a release build.

Warnings

A ⚠ next to a node in the Scene tree means it can't work as set up. Hover it for the reason. See Warnings.

Common problems

My Trigger Volume never fires

  • The player isn't in the group. Select the player and check Node > Groups for gln_player, or whatever the trigger's Only Group says. Leave Only Group empty to react to any body.
  • The player isn't a physics body. Triggers notice bodies such as CharacterBody3D, not plain meshes.
  • Layers don't match. The player's Collision Layer must include a layer in the trigger's Collision Mask.
  • The box is in the wrong place. Check the orange box actually covers where the player walks, including height.
  • It's disabled. Check Start Enabled, and whether anything sends it Disable.

Pressing E does nothing

  • The Interact Zone only listens while the player is inside its box. Check the box covers where the player stands.
  • Check Project Settings > Input Map has the zone's Action (gln_interact by default). The node shows a warning if it's missing. Toggling the plugin off and on adds it back.

My door ends up open when it should be closed

Something is driving the door with Start from a pair of events (enter and exit, or On True and On False). Start is ignored while the door is moving, so a quick in-and-out loses one. Use Go To End and Go To Start instead; see Move.

The player falls through or slides off a moving platform

Make the platform an AnimatableBody3D, not a StaticBody3D. Right-click it in the Scene tree and choose Change Type.

Something moves the wrong way

  • Move: check Space. Local follows the parent's axes, so a turned prefab moves along its own turned axes; World uses the world's axes. The cyan path line shows the actual direction.
  • Rotate: the offset is in the parent's axes, and the pivot is the Rotate node's position. Put the Rotate node on the hinge.

A connection doesn't work, and there's a warning about a missing target

The target was renamed, moved or deleted after the row was made. Open the sender in the Logic I/O panel: the row shows "Missing: …". Pick the target again.

I can't edit some rows; they're greyed out

Those rows belong to a placed scene (a prefab). Open that scene to change them, or add new rows here; see Logic inside placed scenes.

I changed a script's default value and my scenes still have the old one

The editor keeps the old values in memory. Save, then use Project > Reload Current Project before saving any scenes again.

My sound is too loud, too quiet, or plays from the wrong place

Audio Clips start at -12 dB. Turn Positional off for music and announcements; leave it on, and put the node where the sound should come from, for everything else. Check Max Distance isn't smaller than the room.

Still stuck?

Open an issue on GitHub with what you expected, what happened, and the Trace output if you have it.
