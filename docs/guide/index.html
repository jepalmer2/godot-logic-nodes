Documentation

Everything you need to build gameplay with Godot Logic Nodes: setting it up, how the pieces fit together, every node's settings, and ready-made recipes for common setups.

Godot Logic Nodes is a free visual scripting addon for Godot 4. You place Logic Nodes (triggers, movers, timers, counters, sounds) directly in your 3D level, then wire one node's output to another node's input in the Logic I/O panel. A Trigger Volume's On Trigger Enter wired to a door's Go To End is a working proximity door, with no script.

Who it's for

Level designers and artists who want doors, traps, puzzles and moving platforms without learning GDScript, and programmers who'd rather not write the same door script for the hundredth time. If you can use Godot's Inspector, you can use Logic Nodes.

Requirements

  • Godot 4.7 or newer (built and tested on 4.7.2).
  • The standard GDScript build of Godot. The .NET build hasn't been tested.
  • A 3D scene. Logic Nodes are Node3Ds, so they live in the level next to what they control.
